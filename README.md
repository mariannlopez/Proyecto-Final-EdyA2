# Teatro Cali — Boletería del Teatro Municipal

Plataforma web para consultar la cartelera, elegir sillas y comprar boletas
del Teatro Municipal Enrique Buenaventura (Cali).

## Integrantes
- Tu nombre — rama `feature/catalogo`
- Nombre de tu compañero/a — rama `feature/compra`

## Enlaces
- Propuesta gráfica (Figma): (https://www.figma.com/site/sBZxsjVa4GP5ptkQqwWnZq/figma-estructuras-de-datos?node-id=0-1&t=2DxYAM8z2cqrxk2b-1)
- Sitio desplegado (Netlify): (https://calm-chebakia-96b0e1.netlify.app)
- Documento final: `docs/documento-final.pdf`

## Estructuras de datos
Cola, Pila, Árbol n-ario, Trie y Grafo.

ng serve
